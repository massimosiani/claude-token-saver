# Changelog

## 1.3.0

- Generate and merge rules with a Python 3.9+ standard-library helper. Preview every
  change and apply only the reviewed plan, rejecting stale content or altered plans.
- Track managed blocks with stable markers and migrate unambiguous legacy sections.
  Stop without writing on ambiguous Markdown or linked targets.
- Default to three general communication rules; select model compatibility before
  generation and make workflow, formatting and Opus 5 additions opt-in.
- Narrow rules about rereading, testing, configuration approval, prose and diagnostics.
- Show the reminder directly to the user at startup, with no model-context injection.
- Automate rendering, merge and write tests on Linux and macOS; document removal,
  unmeasured savings, runtime requirements and retained license notices.
